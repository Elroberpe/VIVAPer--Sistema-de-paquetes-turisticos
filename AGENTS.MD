\# VIVAAIR — Instrucciones para asistentes de IA



Eres un asistente de desarrollo de software que colabora en el proyecto académico VIVAAIR, un sistema web de reservas de paquetes turísticos.



\## Stack tecnológico



\- Backend: Java + Spring Boot

\- Base de datos: MySQL

\- Frontend: Angular + TypeScript

\- Arquitectura: respetar la arquitectura documentada del proyecto.



\## Instrucciones obligatorias



1\. Antes de implementar, revisa la arquitectura, estructura y convenciones del proyecto.

2\. No inventes requisitos funcionales ni reglas de negocio.

3\. No modifiques archivos fuera del alcance de la tarea.

4\. No agregues dependencias innecesarias.

5\. Reutiliza el código existente cuando corresponda.

6\. Respeta los contratos API establecidos.

7\. Aplica buenas prácticas de seguridad, validación y manejo de errores.

8\. Genera código limpio, modular y mantenible.

9\. Evita la sobreingeniería.

10\. No cambies el esquema de base de datos sin autorización.

11\. No sobrescribas código existente sin revisar su propósito.

12\. No generes funcionalidades adicionales no solicitadas.

13\. Si falta información importante, pregunta antes de implementar.

14\. Explica brevemente los cambios realizados.

15\. Propón pruebas para verificar el funcionamiento.

16\. No declares que una funcionalidad está probada si no ejecutaste las pruebas.



\## Forma de trabajo



Para cada tarea:



1\. \*\*Análisis:\*\* identifica el objetivo, los archivos involucrados y las dependencias.

2\. \*\*Propuesta:\*\* indica qué se implementará y qué archivos cambiarán.

3\. \*\*Implementación:\*\* desarrolla únicamente la funcionalidad solicitada.

4\. \*\*Verificación:\*\* ejecuta las pruebas disponibles o indica cuáles están pendientes.

5\. \*\*Resumen:\*\* presenta los archivos modificados y los resultados.



\## Regla principal



Prioriza la consistencia del proyecto sobre las preferencias particulares del asistente de IA.



El código generado debe integrarse con lo existente, no imponer una arquitectura diferente.
